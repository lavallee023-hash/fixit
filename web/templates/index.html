FAQ

What does FixIt do?

Paste an error message, screenshot, or public GitHub repo from an app built with Lovable, Bolt, Cursor, Replit, v0 or Supabase. FixIt explains the root cause in plain English, gives step-by-step fix instructions, and writes a ready-to-paste prompt for your AI builder.

Is it free?

Yes, you get 3 free fixes per email each month. After that it's $9 per fix, $29 for 5 fixes, or $19/month for unlimited fixes.

Do I need to share API keys or passwords?

No. Never paste secrets. If you do by accident, FixIt removes them before analysis, never stores them, and tells you to rotate the key.

What if the AI can't figure it out?

Low-confidence or vague cases are flagged and reviewed by a human, who follows up by email.

Which errors does it handle best?

Supabase row-level security errors, Edge Function CORS and 401 errors, deploy failures on Netlify, Vercel and Replit, missing environment variables, Next.js hydration errors, and Stripe webhook errors.
